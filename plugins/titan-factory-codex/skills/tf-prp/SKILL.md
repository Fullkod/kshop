# Prp

Inspect actual code and decisions before proposing architecture. Use ../../templates/prp-base.md as a structure guide. Capture objective, value, scope, behavior, acceptance criteria, references, data model, dependencies, rollout and verification. Scale detail to complexity.

Write .titan/plans/prp-<feature>.md when an artifact is appropriate. Plan dependent phases and defer low-level tasks until the phase is inspected. Record unknowns rather than invented schemas.

For planning-only requests stop after the plan. When implementation is already authorized and no material decision is missing, continue with tf-bucle-agentico without duplicate permission questions. Resolve concrete product ambiguities before dependent work.

This skill uses the current context. It does not create a subagent through fork metadata. Delegate only within authorization and host capabilities.
