# Add Manual

Read [GUIDE.md](GUIDE.md) and its references for the module contract, UI, screenshots and export integration. This builds an application feature; use native document/PDF skills for a one-off artifact.
Inspect actual roles, languages, tokens and persistence. Worker/admin and Spanish/English are supported recipes, not mandatory product choices. Enforce editing access server-side and keep internal content out of public manuals. Validate export contents and render PDFs to check pagination/clipping; browser printing alone is not verified export quality.
