# Website 3D

Use [GUIDE.md](GUIDE.md) and [section recipes](references/sections-guide.md) for scroll-stop composition and copy. Confirm product story, audience, CTA and video from supplied context. A generic homepage request does not by itself require cinematic video.
Keep existing brand and chosen design. If video is absent prepare a useful static fallback or obtain the asset; never invent a file. Support reduced motion, keyboard access and mobile. Verify loading, poster fallback and performance. Essential information must remain accessible without video. Validate factual marketing claims.
