# Memory Manager

Use .titan/memory/MEMORY.md as a short index with user/, feedback/, project/ and reference/ entries. Keep shared facts in the target repository, never in the installed plugin. Read relevant entries before relying on past decisions.

Capture a dated fact, scope, reason and source. Distinguish decisions from hypotheses. Mark superseded facts instead of accumulating contradictions. Keep the index near 200 lines and link detailed entries. Current code and user instructions override stale notes.

Do not infer a person's identity from another project. Omit credentials, private conversations and unnecessary personal data. Respect existing memory systems; migrate only if requested. Do not edit Codex settings or claim to disable account memory. Saving a file is not proof of a Git commit or cross-device synchronization.

Update only useful knowledge within authorized work. Do not create commits just to save memory unless requested or part of the accepted workflow. Read-only requests do not authorize writes. Report what was saved and where.
