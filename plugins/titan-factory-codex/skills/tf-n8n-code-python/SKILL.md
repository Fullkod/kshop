# N8N Code Python

Read [GUIDE.md](GUIDE.md) and its data-access, library, pattern and error references. Determine the actual Python runtime: Pyodide restrictions in inherited examples do not automatically apply to native task runners.
Preserve language choice. Verify item access, allowed imports and serialization in that runtime. Test empty and multi-item data. Do not copy JavaScript expression syntax or install packages outside supported mechanisms.
