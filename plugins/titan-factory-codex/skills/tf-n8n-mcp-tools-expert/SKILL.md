# N8N Mcp Tools Expert

Discover the actual tool surface; read [GUIDE.md](GUIDE.md) and the needed [search](SEARCH_GUIDE.md), [validation](VALIDATION_GUIDE.md) or [workflow guide](WORKFLOW_GUIDE.md). Match nodeType formats and profiles to server version. Examples do not prove tools are installed.
