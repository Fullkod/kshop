# New App

Extract the problem, affected role, present cost, solution, main user journey, inputs/outputs and measurable first-version success. Reuse supplied information; ask only questions affecting the product, not a fixed interview.

Create or extend BUSINESS_LOGIC.md within scope. Include requirements, assumptions, boundaries, data ownership, success criteria and implementation sequence. Preserve planning-only requests.

Use Next.js + Supabase + Vercel as the owner's preferred stack for compatible new web projects. Keep EasyPanel for VPS deployment. Preserve existing stacks. Auth, billing, AI, PWA and n8n are optional capabilities.

Read ../../templates/nextjs-supabase/README.md before using the starter. ../../scripts/titan.py scaffold-app copies it only into a new or empty directory. It does not overlay existing apps. Scaffold login/dashboard pages are not finished authentication.

For complex implementation use tf-prp, then proceed when work is authorized and material decisions are resolved.
