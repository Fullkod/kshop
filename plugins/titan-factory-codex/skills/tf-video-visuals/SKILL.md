# Video Visuals

Extract visual moments sized to the requested scope. Define each frame's point, exact labels, composition, aspect and relationship to adjacent frames.
Use warm cream paper, thick hand-drawn outlines, textured pastel fills, labeled diagrams and organic arrows for this style. Strong colors work on outlines, soft fills inside. Follow the user's language/brand; Spanish and 16:9 are defaults for an unspecified Spanish video brief.
[Levy](assets/levy.png) is an optional original mascot for selected Titan branding, not a default for clients. Inspect the asset before image-reference use.
Generate through tf-image-generation or native image tools. Preserve earlier frames. Inspect legibility, accuracy and visual consistency. Regenerate failed frames only within scope. Deliver ordered images tied to script moments; a prompt list is not a finished image package.

For the full original visual palette and drawing rules, read [the optional style preset](references/style-preset.md).
