# Bucle Agentico

Start from the accepted objective and .titan/plans when present. For each phase: inspect code/data contracts, identify reusable parts, derive immediate tasks, implement and run checks tied to the outcome. Record evidence and remaining work.

Do not run dependent DB/API/UI edits concurrently. For authorized independent delegation define ownership and integration points. The seven roles live in ../../agents; files alone do not launch agents.

On errors, reproduce, fix the cause, verify and capture a narrow lesson. Documentation reduces recurrence; it does not guarantee an error never recurs. Avoid unrelated refactoring to match a template.

Incorporate user steering while preserving accepted requirements. Finish when criteria are met, or report the concrete blocker and completed independent work. Distinguish checked behavior from untested integrations. Use the host planning tool or plan file; no Claude-specific task API is required.
