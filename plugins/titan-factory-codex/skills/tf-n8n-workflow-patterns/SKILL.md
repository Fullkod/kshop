# N8N Workflow Patterns

Read [GUIDE.md](GUIDE.md) and its relevant pattern reference. Model input shape, item cardinality, branches, retries, idempotency and failures before selecting nodes. Map actual credentials and versions through the available integration.
Design in a draft/inactive workflow. Verify representative payloads, empty/partial results and item linkage. Activation and external effects must match user scope. Inherited usage statistics are examples, not guarantees.
